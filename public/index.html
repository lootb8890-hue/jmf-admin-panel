الإعدادات

🔗 ربط GitHub — المزامنة بين الأجهزة

لجعل النماذج تظهر تلقائياً على جميع أجهزة المستخدمين، اربط لوحة التحكم بمستودع GitHub.
الخطوات:
1. أنشئ مستودعاً جديداً على GitHub (عام أو خاص)
2. أنشئ ملف admin-models.json في المستودع (يمكن أن يكون فارغاً: [])
3. أدخل رابط المستودع أدناه
4. أدخل Personal Access Token ( من GitHub → Settings → Developer Settings → Tokens )
5. عند إضافة نموذج، سيُرفع تلقائياً إلى المستودع، وسيظهر على جميع الأجهزة

يجب أن يحتوي المستودع على ملف admin-models.json
من GitHub → Settings → Developer Settings → Personal access tokens → Fine-grained tokens
